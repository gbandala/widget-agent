Página de prueba — Widget embed (LOCAL)

Esta página simula un sitio externo que embebe el widget via widget.js.
Usa el token DEV (allowed_origin: http://localhost:3000).
El botón azul aparece abajo a la derecha.

Modo script tag (widget.js)

El widget se carga con el token DEV de NEXT_PUBLIC_DEMO_WIDGET_TOKEN.
Fuente del iframe: http://localhost:3000/embed

Para probar con el token de producción (clariifica.com), reemplaza data-token con el valor de WIDGET_TOKEN_PROD en .env.local y accede desde el dominio autorizado.
