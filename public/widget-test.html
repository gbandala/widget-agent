Página de prueba — Widget embed (LOCAL)

Simula un sitio externo que embebe el widget via widget.js.
Usa el token DEV (allowed_origin: http://localhost:3000).
El botón aparece abajo a la derecha. El iframe carga en segundo plano (requestIdleCallback) para abrirse instantáneo al primer click.

Atributos disponibles en <script data-*>
AtributoValor por defectoDescripción
data-tokenrequeridoToken del widget
data-bot-nameAsistenteNombre del bot en el header
data-welcome-message—Mensaje de bienvenida inicial
data-avatar-url—URL del avatar del bot
data-color#2563ebColor principal del FAB (hex)
data-positionbottom-rightbottom-right | bottom-left

También aceptado como window.widgetConfig = { token, botName, color, ... } antes del script tag.
Control programático (postMessage)

window.frames[0].contentWindow.postMessage({ type: 'widget-open' }, '*')
— desde el host, o desde el iframe hacia el host para cerrar.

Teclado: ESC cierra el widget cuando está abierto.

Para probar con el token de producción, reemplaza data-token con el valor correspondiente y accede desde el dominio autorizado (allowed_origin).
